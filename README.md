# Tesea Desktop

Instaladores do app desktop Tesea. Baixe a versão mais recente em [Releases](https://github.com/Tesea-AI/tesea-desktop-releases/releases/latest).

- **macOS (Apple Silicon)**: `Tesea-<versão>-arm64.dmg`
- **macOS (Intel)**: `Tesea-<versão>-x64.dmg`
- **Windows**: `Tesea-Setup-<versão>.exe`

O código-fonte fica em um repositório privado; aqui ficam apenas os binários publicados.
